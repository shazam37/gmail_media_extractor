Gmail Media Extractor
=====================
Download all your Gmail attachments in one click.


HOW TO RUN
──────────
Windows:
  Double-click GmailMediaExtractor.exe

  If Windows shows a "Windows protected your PC" warning:
    → Click "More info"  →  Click "Run anyway"
  This appears because the app is not commercially code-signed.
  It is safe to proceed.

Mac:
  Double-click GmailMediaExtractor (inside the .app bundle).

  If macOS says "can't be opened because it is from an unidentified developer":
    → Right-click (or Ctrl-click) the app  →  click "Open"  →  click "Open"
  You only need to do this once.


USING THE APP
─────────────
1. Open the app.
2. Your browser will open once for Google sign-in — log in and
   approve the permissions. The app continues automatically.
3. (Optional) Set a date range to only get attachments from a period.
4. Tick which file types you want (or leave "Select All" checked).
5. Choose where to save the files, or leave the default (Downloads).
6. Click "Start Extraction" and watch the progress bar.
7. When done, click "Open Folder" to see your files.


YOUR FILES ARE ORGANISED LIKE THIS
───────────────────────────────────
  GmailMedia/
  ├── PDF Documents/
  ├── Word Documents/
  ├── Spreadsheets/
  ├── Presentations/
  ├── Images/
  ├── Videos/
  ├── Audio/
  └── Archives/


SMART RE-DOWNLOAD PROTECTION
──────────────────────────────
If you run the app a second time it will NOT re-download files you
already have. Only genuinely new attachments will be downloaded.


SIGNING OUT / SWITCHING ACCOUNTS
──────────────────────────────────
Click "Sign out / switch account" inside the app, then restart it.
Your browser will ask you to sign in again with any Google account.


PRIVACY
───────
• The app only reads attachment files — it cannot read email bodies,
  send emails, or delete anything.
• Your sign-in token is stored only on your own computer.
• No data is sent anywhere except Google's own servers.
